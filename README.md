# BOT-DE-STATUS-SAMP-PRA-VPS
BOT DE STATUS SAMP
1️⃣ PORTUGUÊS

1.1 🧠 O que esse bot faz
Mostra o STATUS do servidor SA-MP no Discord
Atualiza automaticamente:

2.1 🟢 ONLINE / 🔴 OFFLINE

2.2 👥 Players online

2.3 📶 Ping

2.4 🌐 IP do servidor

Edita sempre a mesma mensagem (não spamma o canal)
Possui botões:
4.1 YouTube
4.2 Instagram
4.3 Site
1.2 ⚙️ Como usar (resumo rápido)
Instale Python 3.10 ou superior
Instale a biblioteca:
pip install discord.py
Abra o arquivo main.py
Coloque o TOKEN do bot:
TOKEN = "COLOQUE_SEU_TOKEN_AQUI"
Configure:
SAMP_IP = "SEU_IP"
SAMP_PORT = 7777
STATUS_CHANNEL_ID = ID_DO_CANAL
Execute:
python main.py
✅ O bot começa a atualizar o status automaticamente
